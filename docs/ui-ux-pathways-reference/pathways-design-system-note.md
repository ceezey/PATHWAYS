## Authority

BRAND FOUNDATIONS
Defines product character, UX principles, accessibility philosophy,
safety-by-design, language, and interaction intent.

COLOR FOUNDATIONS
Defines exact approved color tokens and color usage.
This file is authoritative for color.

UI FOUNDATIONS
Defines exact spacing, radius, sizing, component, surface, density,
and layout rules.
This file is authoritative for interface implementation.

## Conflict Resolution

When documents appear to conflict:

1. Exact token/specification beats descriptive guidance.
2. Accessibility and safety requirements beat aesthetic preference.
3. Existing approved component behavior beats invention.
4. User workflow context beats decorative consistency.
5. If a required value is missing or ambiguous, DO NOT invent it.
   Flag the ambiguity for human review.

## Non-Negotiable Product Rules

PATHWAYS is an operational project information workspace.

Optimize for:
- clarity
- continuity
- accessibility
- traceability
- low cognitive effort
- minimum unnecessary interaction
- human control

Do not optimize for:
- visual novelty
- maximum information density
- minimum clicks at the expense of safety
- dashboard aesthetics over workflow usability
- autonomous-looking system behavior

Before producing a screen, determine:

USER
→ TASK
→ CONTEXT
→ REQUIRED INFORMATION
→ PRIMARY ACTION
→ SAFETY / ACCESS CONSTRAINTS
→ APPROPRIATE PATHWAYS PATTERN

Then design.

# Go-To-Market Strategy (GTM)

**Status:** Draft
**Version:** 2.0
**Last reconciled:** 2026-10-01
**Owner:** PATHWAYS capstone team

This is an internal rollout plan, not a commercial launch. Source: developer answers 2026-10-01.

## 1. Product Summary (GTM View)

PATHWAYS is an internal project information management system with rule-based decision support, rolled out to Plan International Pilipinas. See `IDEA.md` and `docs/prd-pathways.md`.

## 2. Target Audience

| Audience | Detail |
|---|---|
| Rollout organization | Plan International Pilipinas |
| Year-one scale | 1 organization, about 15 staff users |
| Roles | System Administrator, Program Manager, Grant Manager, Project Manager, Monitoring and Evaluation Officer, Project Officer |
| External viewers | Donors, sponsors and partners read the public tracker only |

## 3. Pricing Model

Not applicable: client-sponsored internal system with no pricing (`docs/ues-pathways.md`).

## 4. Positioning & Messaging

- Less repeated preparation of field data before it can be used.
- One place for project, activity and Beneficiary records.
- Alerts and recommendations are decision support; staff review and approve.
- Public visibility is limited to approved, non-sensitive summaries.

## 5. Launch Channels & Tactics

| Channel | Purpose |
|---|---|
| Hands-on training sessions | Teach each role its screens |
| PDF user guide | Reference for staff |
| Pilot group | Early use before wider rollout |

## 6. Launch Phases

| Phase | Content | Dates |
|---|---|---|
| Training | Hands-on sessions per role | Not established: not set |
| Pilot | Pilot group uses PATHWAYS | Not established: not set |
| Wider rollout | Remaining staff | Not established: not set |

Rollout is also gated on production readiness (`docs/qad-pathways.md` section 6.1, `docs/audit-pathways-manuscript-alignment-20261001.md`).

## 7. Success Metrics (30-day post-launch)

| Metric | Target |
|---|---|
| Pilot staff login | 80% of pilot staff log in weekly |
| Field data | 2 field datasets imported |
| Reporting | First monthly report generated in PATHWAYS |

## 8. Answer Surfaces (AI Visibility)

Not applicable: an internal tool has no search or answer-engine presence to manage. The only public surface is the Public Project Tracker (`docs/prd-pathways.md` PRD-F13; manuscript BUILD 5.2), limited to approved summaries.

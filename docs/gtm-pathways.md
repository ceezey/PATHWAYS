# Go-To-Market Strategy (GTM)

## Status

Commercial GTM is not an active implementation target.

Current "launch" context is capstone defense, controlled testing, stakeholder review, and possible future pilot planning.

## Positioning

Primary:

> Metadata-driven project information management for humanitarian and development organizations.

Supporting:

> Descriptive monitoring, SADDD, rule-based alerts, and human-reviewed decision support.

Avoid:
- AI claims;
- autonomous decision claims;
- real-time interoperability claims;
- production-readiness claims without evidence.

## Phases

1. core features;
2. supporting features;
3. security/privacy/QA/UAT;
4. controlled demonstration/pilot planning;
5. deployment planning only after separate authorization.

## Metrics

Deferred until a real pilot/deployment is authorized.
